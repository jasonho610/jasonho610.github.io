# Background music

The player in the bottom-left corner looks for these two files. Until they exist it hides itself,
so the site is never broken by their absence.

| File | Track |
|---|---|
| `hard-bop-rainy-night.mp3` | “Hard Bop Rainy Night (Bright Late Session)” — Alex Morgan |
| `too-cool-for-school.mp3`  | “Too Cool for School” — NoKings XXX |

Both are CC BY 4.0 on the Free Music Archive, which means they can be hosted here as long as the
credit stays in the footer. Downloading from FMA needs an account, so grab them yourself:

- https://freemusicarchive.org/music/alex-morgan/moods-atmospheres-vol-4/hard-bop-rainy-night-bright-late-session/
- https://freemusicarchive.org/music/nokings-xxx/too-cool-for-school/too-cool-for-school/

Rename each download to the filename above and drop it in this folder. To use different music,
edit the `TRACKS` array at the top of `assets/js/ambience.js` and update the credit in the footer
of `index.html`.
